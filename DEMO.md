# ProfLM: 90-second walkthrough

Open `/` (demo mode works without a key). Matches the presentation demo.

1. **Type the homework** `Solve x² − 5x + 6 = 0 for me`. ProfLM answers with a question, not a solution.
2. **Reply "finding x? idk"**. The level card sets *Starting out* and says why. The explanation uses simple words and an analogy. The class file it comes from lights up on the left.
3. **Explain it back**. Write one idea only. The check says *Partly there*, shows what you have right, and asks one question. The next step stays locked.
4. **Explain it fully**. *Understood*. The mastery map turns green. If you got it on the first try, the level moves up.
5. **Next step**. Wording becomes more precise. Open **Try it** and drag the marker to find where the practice curve meets zero.
6. **Click "Just give me the answer"**. It redirects. The model is not called.
7. Show the **token meter** and the **Teacher view** (mock data, class-level numbers only).
